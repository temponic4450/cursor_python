Part 1. Windows Python 세팅 (단계별)

2026년 기준 권장 구성: Python 공식 설치 · VS Code · venv · pip 또는 uv

1. Python 설치

  • 공식 홈페이지(python.org) → Windows Installer (64-bit) 다운로드
  • 설치 시 반드시 체크: Add python.exe to PATH
  • 설치 확인: python --version 또는 py --version

2. VS Code 설치

  • Extension: Python (Microsoft), Pylance, Black Formatter, Jupyter

3~6. 프로젝트 & 가상환경

cd D:\Project\Python
python -m venv .venv

# PowerShell 활성화

# CMD 활성화

python -m pip install --upgrade pip

pip install -r requirements.txt

10. VS Code 인터프리터

Ctrl+Shift+P → Python: Select Interpreter → .venv 선택

python main.py

14. uv 사용 (최신 권장)

Part 2. Python 버전 & Anaconda 안정성

Anaconda Python 3.13.9는 Stable한가?

네. Anaconda에 포함된 Python 3.13.9는 충분히 안정적인(Stable) 버전입니다. 3.13.9는 3.13 계열의 9번째 패치(Maintenance) 릴리스로, 새 기능 추가보다 버그 수정·보안 패치 중심입니다.

Stable 최신 버전 비교 (2026년 8월 기준)

Python 3.14.x가 최신 안정 메이저 버전이지만, '최신'과 '가장 추천'은 항상 같지 않습니다.

항목Python 3.13.9Python 3.14.x
안정성⭐⭐⭐⭐⭐ (매우 검증됨)⭐⭐⭐⭐☆ (상대적으로 새로움)
라이브러리 호환성⭐⭐⭐⭐⭐⭐⭐⭐☆☆ (일부 미지원 가능)
ML/Data Science⭐⭐⭐⭐⭐ (권장)⭐⭐⭐☆☆ (주의 필요)
신규 프로젝트⭐⭐⭐⭐⭐⭐⭐⭐⭐☆

Anaconda 내 Stable Python 버전

Anaconda에서 가장 안정적으로 많이 쓰이는 버전: Python 3.12.x, Python 3.11.x. 3.13.9도 stable하지만 ML/GPU 라이브러리 호환성을 고려하면 3.12.x가 더 무난한 경우가 많습니다.

최신보다 한두 단계 이전 버전 선호 — PyTorch, TensorFlow, CUDA, GPU Driver, ML 라이브러리 호환성 때문.

개인 학습용으로 Anaconda?

운영 반영이 아닌 개인 학습·분석 목적이라면 Anaconda는 편리합니다 (Jupyter, pandas 등 즉시 사용). Python 생태계(venv, pip, requirements.txt)를 깊이 이해하려면 Python 공식 설치가 더 유리합니다.

셋 중 하나만 설치한다면

1순위 Python 공식 설치 + venv — ★★★★★

2순위 Miniconda — ★★★★☆ (GPU/ML 실험 시)

3순위 Anaconda Full — ★★★☆☆ (빠른 입문용)

여러 OS(Windows/Mac) 경험 관점

# Windows
python -m venv .venv
.venv\Scripts\activate
pip install pandas sqlalchemy

# Mac (거의 동일)
python3 -m venv .venv
source .venv/bin/activate
pip install pandas sqlalchemy

실무 서버(Linux, Airflow, ETL)에서는 python3 + venv + pip + requirements.txt 구조가 일반적입니다. Anaconda(conda)는 별도 생태계이며, 플랫폼 이동성은 좋지만 실무와는 거리가 있습니다.

Part 4. MLOps / ML Engineer 환경 (2026년 기준)

현업 표준: Python + 가상환경(uv/venv/conda) + Docker + Git + VS Code

1. ML Engineer 환경 구조

개발 PC (Windows/Mac/Linux)
├── Python 3.11 ~ 3.13
├── Virtual Environment (uv / venv / conda)
├── VS Code / PyCharm
├── Git

→ 로컬에서 실험하고 Docker로 재현

2. 가상환경 사용 현황

1순위: uv

uv init ml-project
cd ml-project
uv add torch pandas scikit-learn

pip보다 빠름 · 재현성 좋음 · Python 버전 관리 가능

2순위: conda / mamba (GPU, CUDA, 데이터 사이언스)

conda create -n ml python=3.12
conda activate ml

3순위: venv + pip (Backend ML API, FastAPI, MLOps 서비스)
